# Burgundy – Wedding Invite

A standalone interactive wedding invitation featuring a sealed envelope,
floral liner, wax seal, and full-screen invitation reveal.

Open `index.html` directly in a browser or publish this folder as-is. Keep
the `invitation-assets` folder beside it so the botanical artwork, portrait,
deckled paper edge, and closing wax seal load correctly. This is the burgundy
version currently in progress. This project does not depend on the separate
`heirloom` project.
