# Wedding Opening Card

This folder is a standalone copy of the formal opening card from the Wedding Invite project. It does not include the envelope or the rest of the invitation.

## Reuse it

Copy the entire `wedding-opening-card` folder into another project. Keep the `assets` folder beside `index.html` so the two floral images continue to load.

## Change the client details

Open `index.html` and edit the `invitation` object near the bottom of the file. The names, date, time, venue, location, and invitation wording are all controlled there.

The visual colors can be changed using the variables at the top of the stylesheet: `--paper`, `--surround`, `--ink`, `--muted`, and `--gold`.
